# Personal Finance Tracker

A simple desktop application to track income and expenses using Python, Tkinter, SQLite, and Matplotlib.

## Features
- Add and manage transactions
- View categorized expense pie chart
- Store data persistently in SQLite
- Clean and simple GUI with Tkinter

## How to Run
1. Install Python 3
2. Run `main.py`
3. Dependencies: `matplotlib`
